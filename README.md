# Демо кассы пополнения

Локальный прототип депозитного виджета на React, Vite и shadcn/ui. Пользователь выбирает Crypto или Fiat, затем способ оплаты и переходит к его форме. Для Польши демо предлагает BLIK, банковский перевод, карту и другие методы. Выбор валюты доступен в Fiat; страна в демо фиксирована как Польша.

Платежи, комиссии, лимиты, статусы и криптоадреса — демонстрационные. Адреса и QR-коды намеренно недействительны. Не вводите реальные платёжные данные и не отправляйте средства. Реальная доступность, суммы и реквизиты должны поступать от платёжного провайдера.

## Иконки и логотипы

- Для элементов интерфейса используйте [Lucide](https://lucide.dev/icons/) через `lucide-react`: навигация, раскрытие, копирование и статусы. Например, `ChevronDown` для раскрывающихся элементов и `ChevronRight` для перехода к способу оплаты. Сохраняйте единый размер и толщину линий; декоративным иконкам задавайте `aria-hidden`, а кнопкам с одной иконкой — доступное имя.
- Для брендов и платёжных методов используйте `@tabler/payments-react` и проверенные оригинальные логотипы, если точного бренда в библиотеке нет. Размещайте их в едином контейнере. Источники отдельных файлов описаны в [`public/payment-logos/ATTRIBUTION.md`](public/payment-logos/ATTRIBUTION.md).
- Не заменяйте фирменные платёжные знаки универсальными иконками, если доступен корректный логотип. Иконки интерфейса и фирменные знаки выполняют разные задачи.

## Запуск

```bash
pnpm install
pnpm dev
```

## Storybook

```bash
pnpm storybook
```

Откройте `http://localhost:6006`: разделы Foundations, Controls, Payment components и Screens показывают те же компоненты, что используются в кассе. shadcn/ui хранится в `src/components/ui`; настройки темы находятся в `src/index.css`. Новые состояния добавляйте в `src/stories` рядом с существующими историями.

Проверка:

```bash
pnpm build
pnpm lint
```
